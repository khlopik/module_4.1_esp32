# module_4.1_esp

Прошивка для мікроконтролера **ESP32-S3** (4D Systems Gen4 R8N16) на ESP-IDF + FreeRTOS.
Це друга половина пари **STM32 ↔ ESP32**: STM32 обробляє кнопки, енкодер і RGB-світлодіоди,
а ESP32 керує своїм адресним світлодіодом та повідомляє про натискання кнопки.
Контролери спілкуються між собою через UART.

## Модулі

| Модуль   | Файл              | Призначення                                  |
| -------- | ----------------- | -------------------------------------------- |
| `button` | `button.cpp/.hpp` | Кнопка на GPIO7                              |
| `led`    | `led.cpp/.hpp`    | Адресний світлодіод WS2812 на GPIO48          |
| `uart`   | `uart.cpp/.hpp`   | Обмін повідомленнями з STM32                 |

## Піни ESP32

| Пристрій     | Пін     | Напрямок | Примітка                              |
| ------------ | ------- | -------- | ------------------------------------- |
| Кнопка       | GPIO7   | вхід     | активний рівень LOW, 50 мс натискання |
| WS2812       | GPIO48  | вихід    | 1 світлодіод, формат GRB             |
| UART2 TX/RX  | GPIO17 / GPIO16 | вихід / вхід | 115200, 8N1          |

## З'єднання з STM32

| ESP32           | STM32          | Напрямок       |
| --------------- | -------------- | -------------- |
| GPIO17 (TX)     | PA10 (RX)      | ESP32 → STM32  |
| GPIO16 (RX)     | PA9 (TX)       | STM32 → ESP32  |
| GND             | GND            | спільна земля  |

## Протокол UART

115200 бод, 8N1, текстові рядки ASCII, роздільник — перевід рядка `\n`.

**STM32 → ESP32**

| Команда     | Дія                                          |
| ----------- | -------------------------------------------- |
| `ON:1`      | увімкнути WS2812                            |
| `OFF:1`     | вимкнути WS2812                             |
| `R:<value>` | встановити яскравість червоного, 0…255       |
| `G:<value>` | встановити яскравість зеленого, 0…255        |
| `B:<value>` | встановити яскравість синього, 0…255         |

**ESP32 → STM32**

| Команда   | Дія                                                    |
| --------- | ----------------------------------------------------- |
| `PRESS`   | кнопку натиснуто → STM32 вмикає свій вбудований LED   |
| `RELEASE` | кнопку відпущено → STM32 вимикає свій вбудований LED   |

## Логіка роботи

- **Кнопка** — натискання та відпускання надсилають `PRESS` / `RELEASE` на STM32.
- **`ON` / `OFF`** — вмикають або вимикають WS2812. Яскравість компонент зберігається,
  тому `ON` повертає останній встановлений колір.
- **`R` / `G` / `B` зі значенням** — встановлюють яскравість відповідної компоненти.
  Якщо світло ввімкнено, нове значення застосовується одразу.

## Збірка

```bash
pio run             # збірка
pio run -t upload   # прошивання
pio device monitor  # монітор (115200)
```

Платформа: `espressif32`, плата: `4d_systems_esp32s3_gen4_r8n16`, фреймворк: `espidf`.
Компоненти: `espressif/button`, `espressif/led_strip` (тека `managed_components`).
Задачі FreeRTOS: `Check messages` (прийом), `Send messages` (передача).
